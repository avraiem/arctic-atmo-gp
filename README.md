# arctic-atmo-gp
This repository provides a modular and extensible framework for **extracting, cleaning, and modeling atmospheric data over the Arctic region**. It is designed to support applications such as:

- **Safe autonomous ship navigation** in ice-covered waters  
- **Informative Path Planning (IPP)** and adaptive environmental monitoring  
- **Gaussian Process (GP)** modeling of sparse, uncertain fields  
- Exporting atmospheric datasets for external users as Excel/CSV files
